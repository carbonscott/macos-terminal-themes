# Conway terminal themes

Light-first color themes for macOS Terminal.app, plus a dark companion.

| Profile | Background | Foreground |
| --- | --- | --- |
| `conway-paper.terminal` | `#FAF7EE` | `#3C3A31` |
| `conway-parchment.terminal` | `#F6EDDA` | `#4A4432` |
| `conway-sage.terminal` | `#EEF0DF` | `#414A32` |
| `conway-dark.terminal` | `#000000` | `#E1E7A0` |

## Install

Double-click a `.terminal` file, or import it from Terminal:
Settings → Profiles → ⋯ → Import…

Each profile sets JetBrains Mono Regular 14pt and a 100x30 window, and exports
`BG_COLOR` and `TERM_THEME` on startup so shell config can react to the theme.

## iTerm2

iTerm2 color presets converted from these profiles live in
[iterm2-conway-themes](https://github.com/carbonscott/iterm2-conway-themes).
